# 🚀 Employee Leave & HR Analytics System

An analytics-driven HR management project developed during internship training at Paarsh Infotech Pvt. Ltd.

This project automates employee leave management, attendance tracking, workforce reporting, and HR analytics using **Python, SQL, Machine Learning, and Power BI**.

---

# 📌 Project Overview

The **Employee Leave & HR Analytics System** helps organizations manage and analyze employee-related data efficiently.

Traditional HR systems often rely on:
- Manual spreadsheets
- Paper-based leave management
- Offline attendance tracking

These methods lead to:
- Data redundancy
- Human errors
- Delayed reporting
- Poor workforce insights

This system provides an automated and analytics-driven HR solution.
